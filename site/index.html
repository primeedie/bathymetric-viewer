Which GEBCO file should I download?
  1. Open the GEBCO download app ↗ and draw a small regional area.
  2. Choose the elevation grid in Data GeoTIFF or ESRI ASCII format, using geographic WGS 84 coordinates.
  3. Unzip the download and choose its .tif or .asc file here.

Use elevations in metres, positive upward. Shaded images, TID grids, UTM grids, and global files are not supported. ASCII files must use geographic WGS 84 coordinates.

Have a NetCDF (.nc)? Download GeoTIFF instead, or convert it to viewer JSON with the repository’s tools/prepare.py.

Switch grids using the selector above. Uploaded grids show terrain and cell elevations; derived contour overlays are available for the bundled dataset only.
